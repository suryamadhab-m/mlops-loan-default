# mlops-loan-default

TCS Capstone Use Case 1A - Loan Default Prediction Pipeline with Automated Retraining

## Tech Stack
PostgreSQL, Apache Airflow, XGBoost, Great Expectations, MLflow, FastAPI, Docker, GitHub Actions, Evidently AI, Scikit-learn

## Setup
1. Clone the repo
2. Copy .env.example to .env and fill credentials
3. Run docker-compose up -d
4. Access MLflow at http://localhost:5000
5. Access Airflow at http://localhost:8080
6. Access API at http://localhost:8000
